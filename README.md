# School ERP System

A lightweight School ERP web application built with Flask and SQLite.

## Features
- Dashboard with student, teacher, class, attendance, and fees metrics.
- Student management.
- Teacher management.
- Class management.
- Attendance tracking.
- Fee payment tracking.

## Run locally
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open: `http://localhost:5000`
